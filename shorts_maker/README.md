# 쇼츠 메이커

내가 찍은 영상을 넣으면 **Claude가 쇼츠로 편집**해 줘요. 그린룸의 "버튼 하나로 영상 만들기"를 코덱스 대신 Claude로 만든 버전이에요.

## 하는 일
1. **음성 인식**: 영상 속 말을 시간과 함께 받아 적어요 (faster-whisper, 내 컴퓨터에서 무료로 실행)
2. **장면 보기**: 영상에서 사진 16장을 뽑아 Claude에게 보여줘요
3. **Claude 편집 계획**: 가장 강한 장면을 맨 앞으로, 재밌는 구간 고르기, 제목·상단 문구·자막 다듬기, 일본어 번역, 해시태그·설명
4. **호흡 자르기**: 0.45초 넘는 침묵을 자동으로 잘라 템포를 빠르게
5. **렌더링**: 9:16(1080x1920)으로 변환 (가로 영상은 흐린 배경 위에 배치), 상단 문구와 자막을 입혀 **한국어·일본어 버전 2개**를 만들어요

링크(URL)는 받지 않아요. 직접 찍었거나 사용 권리가 있는 영상만 넣어 주세요.

## 준비 (처음 한 번)
1. [Python 3.10 이상](https://www.python.org/downloads/)과 [ffmpeg](https://ffmpeg.org/download.html)을 설치해요.
2. 이 폴더에서 `pip install -r requirements.txt`
3. [Claude Console](https://console.anthropic.com)에서 API 키를 발급받아 환경 변수로 넣어요.
   - Mac/Linux: `export ANTHROPIC_API_KEY=sk-ant-...`
   - Windows: `setx ANTHROPIC_API_KEY sk-ant-...` (창을 새로 열어야 적용)
4. 한글·일본어 자막 글꼴로 **Noto Sans CJK** (또는 Noto Sans KR)를 설치해요. 다른 글꼴은 `--font "글꼴 이름"`으로 바꿀 수 있어요.

## 쓰는 법
```bash
# 기본: 쇼츠 1개, 한국어+일본어
python shorts_maker.py 내영상.mp4

# 쇼츠 3개, 자막 스타일과 편집 요청을 말로
python shorts_maker.py 내영상.mp4 --count 3 \
  --style "검정 배경에 하얀 글자, 화면 가운데" \
  --note "개구리가 점프하는 장면을 맨 앞에" --channel "@내채널"
```

결과는 `shorts_out/` 폴더에 생겨요.

| 파일 | 내용 |
|---|---|
| `내영상_1_ko.mp4`, `내영상_1_ja.mp4` | 완성된 쇼츠 (한국어/일본어) |
| `내영상.upload.txt` | 업로드할 제목·설명·해시태그 |
| `내영상.plan.json` | Claude의 편집 계획 (구간·자막·스타일) |
| `내영상.transcript.json` | 음성 인식 결과 (다음 실행 때 재사용) |

**고치고 싶을 때:** `plan.json`에서 자막 글자나 구간 시간을 직접 고친 뒤 `--plan shorts_out/내영상.plan.json`으로 실행하면 Claude를 다시 부르지 않고(무료) 렌더링만 다시 해요.

## 옵션
| 옵션 | 설명 |
|---|---|
| `--count` | 만들 쇼츠 개수 (기본 1) |
| `--max-sec` | 최대 길이 초 (기본 59) |
| `--style` | 자막 스타일을 말로 요청 |
| `--note` | 편집 요청을 말로 |
| `--channel` | 화면 아래 작게 넣을 채널명 |
| `--langs` | `ko`, `ja`, `ko,ja` (기본) |
| `--whisper` | 음성 인식 정확도: `tiny`/`base`/`small`(기본)/`medium`/`large-v3`. 클수록 정확하고 느려요 |
| `--no-trim` | 침묵 자르기 끄기 |
| `--plan` | 저장된 계획으로 다시 렌더링 |

## 비용
- 음성 인식과 렌더링은 내 컴퓨터에서 무료로 돌아가요.
- Claude 호출은 영상 1개당 1번이에요(Claude Opus 5.5). 사진 16장과 대사를 보내므로 보통 한 번에 몇백 원 수준이에요.

## 올리기 전에
- 유튜브에 올릴 때 AI로 만든 사실적인 장면이 있다면 "변경되거나 합성된 콘텐츠" 표시를 해 주세요.
- 일본어 버전을 따로 올릴 때는 내용이 같은 영상을 대량으로 올리지 말고, 일본어 전용 채널에 올리는 게 좋아요.
