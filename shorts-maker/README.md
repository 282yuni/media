# 쇼핑 쇼츠 메이커

상품 영상·사진을 넣으면 **AI가 대본을 쓰고 → 음성·자막을 입혀 → 세로 쇼츠 4종**을 만들어 줍니다.

| 버전 | 내용 |
|---|---|
| 한국 유튜브 | 한국어 대본, "영상 속 상품 확인" 유도 |
| 한국 인스타 | 다른 표현과 다른 목소리, "프로필 링크" 유도 |
| 일본 유튜브 | 일본어로 새로 쓴 대본과 일본어 음성 |
| 일본 인스타 | 일본어 릴스용 |

버전마다 `제목·설명글(.txt)`도 함께 나옵니다. 설명글에는 제휴 링크, **쿠팡 파트너스 고지 문구**(필수), 해시태그가 들어 있습니다.

## 1. 준비 (PC에서 한 번만)

1. Python 3.10 이상, **ffmpeg**를 설치합니다.
   - 윈도우: `winget install Gyan.FFmpeg`
   - 맥: `brew install ffmpeg`
2. 이 폴더에서 `pip install -r requirements.txt`를 실행합니다.
3. API 키를 환경변수로 넣습니다.
   - `ANTHROPIC_API_KEY`: Claude 대본용 (console.anthropic.com에서 발급)
   - `ELEVENLABS_API_KEY`: 고품질 음성용 (elevenlabs.io에서 발급). **없으면 무료 음성(edge-tts)으로 자동 대체**됩니다.

## 2. 휴대폰으로 쓰기 (영상 속 방식)

```
python app.py
```
PC와 휴대폰을 같은 와이파이에 연결한 뒤, 휴대폰 브라우저에서 `http://<PC IP주소>:8000`을 엽니다.
영상/사진을 고르고 상품명과 링크를 넣은 다음 **영상 만들기**를 누르면, 몇 분 뒤 다운로드 버튼이 나옵니다.

## 3. PC 명령줄로 쓰기 (대량 제작)

```
python make.py --product "전자레인지 계란찜기" --notes "3분 완성, 설거지 쉬움" \
  --link https://link.coupang.com/a/xxxx 영상1.mp4 사진1.jpg
```
결과는 `output/` 폴더에 저장됩니다. `--only ko_youtube ko_instagram`처럼 일부 버전만 만들 수도 있습니다.

## 목소리 바꾸기

ElevenLabs 보이스 ID를 환경변수 `VOICE_KO_YT`, `VOICE_KO_IG`, `VOICE_JA_YT`, `VOICE_JA_IG`에 넣으면 됩니다.

## 꼭 지킬 것

- **소스 영상은 직접 찍었거나 판매자·제조사가 사용을 허락한 것만** 쓰세요. 남의 쇼츠를 가져와 다시 만들면 저작권 신고를 받거나 수익 창출이 거부될 수 있습니다.
- 업로드할 때 설명글의 **제휴 고지 문구를 지우지 마세요**. 공정위 표시광고 지침에 따른 의무사항입니다.
- 비용: 대본 1세트(4종)는 Claude 호출 1번으로 만듭니다. 음성은 ElevenLabs 요금제의 글자 수 한도에서 차감됩니다.
