# 숏드라마 현지화 도구 — 화면 설계 (참고 영상 분석 기반)

참고: 유튜브 '돈벌리는수다' 영상(vn3c4uGKSXk) 12:40–18:30 구간에 나온 프로그램 화면.

## 전체 구성
- 다크 테마, 초록색 강조색
- 왼쪽 고정 메뉴 6개: 크리에이터 찾기 / 영상 찾기 / 영상 분석 / 대본 생성 / 음성 생성 / 파일 다운로드
- 별도 자동 편집 프로그램: 폴더 선택 → 진행 바 → 약 1분 뒤 MP4 완성

## 화면별
1. **크리에이터 찾기**: 날짜 범위, 조회수 ○○ 이상, 키워드 → 크리에이터 목록
2. **영상 찾기**: 탭(키워드 검색 / 관심 채널에서 찾기), 좋아요 ○○ 이상, 댓글 ○○ 이상, 영상 URL 입력 → 썸네일 카드 + 저장 버튼
3. **영상 분석**: 줄거리 요약 + 판정 `🟢 초록불 (바로 제작)` / `🔴 빨간불` + 이유 설명
4. **대본 생성**: 원본(번역)과 각색본을 나란히 표시, 해설(내레이션) 줄 표시
   - 예) 원본 "집은 다 챙겨놨으니까 얼른 나가거라" → 각색 "당장 집 밖으로 꺼져!"
5. **음성 생성**: 역할별 보이스 배정 표 (역할 / 성격(악역·선역, 남·여, 나이) / 성우 드롭다운 / 미리듣기)
   - "역할 성격에 맞춰 성우가 자동 배정되었어요. 드롭다운에서 바꿀 수 있어요"
6. **파일 다운로드**: 음성(MP3), 자막(SRT), 각색대본(DOCX), 원본대본(DOCX), 영상(MP4)

## 사용 순서
영상 찾기 → 저장 → 영상 분석(초록불 확인) → 대본 생성 → 음성 생성 → 파일 다운로드 → 자동 편집으로 MP4 완성

## 직접 만들 때 기술 대응
| 기능 | 기술 |
|---|---|
| 영상 입력 | 사용자가 파일/URL 직접 입력 (플랫폼 자동 수집은 약관 문제로 제외) |
| 중국어 받아쓰기 | Whisper |
| 분석·각색·해설 | Claude API |
| 역할별 음성 | Edge TTS(무료) 또는 ElevenLabs |
| 원본 목소리 제거 | Demucs |
| 합성·자막 | FFmpeg |
