유튜브 자동완성으로 넓히기

씨앗 키워드를 넣으면 사람들이 실제로 검색하는 연관 검색어를 가져와요. (API 한도 안 씀)

제목 붙여넣기로 뽑기

유튜브 홈·인기 쇼츠에서 눈에 띈 제목들을 복사해 붙여넣으면 자주 나오는 단어를 뽑아요.

후보 키워드

눌러서 선택하세요. 관심 있는 3~5개만 고르는 게 한도 아끼는 요령이에요.

조건

키워드 1개 검증 = 약 102단위. 하루 한도로 키워드 90개 정도 검증할 수 있어요.

결과

키워드별 상위 50개 영상 중 조회수 구간별 개수. 큰 숫자가 많을수록 "이 주제로 만들면 이 정도는 기대할 만하다"는 근거예요.

키워드10만+50만+100만+500만+중간값

10만+ 50만+ 100만+ · 구독자의 10배+ 작은 채널에서 터진 영상 = 채널 힘이 아니라 소재 힘

관심 목록

저장한 영상의 조회수를 새로고침할 때마다 기록해요. 며칠 간격으로 모으면 죽었다 다시 뜨는 소재가 보여요.

재상승 최근 하루 증가량이 평생 평균의 1.5배 이상 · 정체 최근 증가가 평생 평균의 10% 미만

YouTube API 키

무료로 발급돼요. Google Cloud Console → 새 프로젝트 → "YouTube Data API v3" 사용 설정 → 사용자 인증 정보 → API 키 만들기. 키는 이 브라우저에만 저장돼요.

예시 데이터

API 키 없이 화면을 둘러볼 수 있게 가짜 예시 데이터를 넣어요. 실제 영상이 아니에요.

이 도구에 없는 기능

남의 영상을 링크로 받아 잘라 올리는 자동 편집 기능은 넣지 않았어요. 허락 없이 다른 사람의 영상을 다시 올리면 저작권 경고와 수익 정지, 채널 삭제로 이어질 수 있어요. 여기서 찾은 주제는 직접 찍거나 직접 만든 영상으로 풀어 주세요.
