# 소재 탐색기

잘 터지는 주제를 찾아 **내 방식으로 새로 만들기** 위한 도구예요. `index.html` 파일 하나로 동작해요.

## 기능
1. **키워드 찾기**: 유튜브 자동완성 연관어 가져오기, 붙여넣은 제목에서 자주 나오는 단어 뽑기
2. **키워드 검증**: 키워드별 상위 50개 영상의 조회수 구간(10만/50만/100만/500만+) 개수와 중간값
3. **영상 분석**: 조회수 배지, 하루 평균 조회수, 구독자 대비 조회수(작은 채널에서 터진 영상) 정렬
4. **관심 목록**: 조회수를 새로고침할 때마다 기록해서 "죽었다 다시 뜨는" 영상 표시, 아이디어 메모

남의 영상을 받아 자동으로 잘라 올리는 기능은 저작권 문제로 넣지 않았어요.

## 쓰는 법
1. Google Cloud Console에서 프로젝트를 만들고 **YouTube Data API v3**를 사용 설정한 뒤 API 키를 발급받아요 (무료, 하루 10,000단위).
2. `index.html`을 브라우저로 열고 **설정** 탭에 키를 저장해요. 키는 그 브라우저에만 저장돼요.
3. 키워드 1개 검증에 약 102단위가 들어요. 하루에 키워드 90개 정도 검증할 수 있어요.

API 키에 "웹사이트 제한"을 걸었다면, 이 파일을 여는 주소가 허용 목록에 있어야 해요.
