# 인수인계 — 전화상담 프로그램 (새 대화에서 이어서 작업할 때 먼저 읽기)

## 사용자
- 텔레마케터. 개발자가 아님 → **쉬운 한국어로만** 답하고, 전문 용어·영어는 풀어서 설명.
- 지금 회사: **에셜론** (소상공인 대상 네이버 플레이스 상위노출 마케팅). 폰 2대(갤럭시 S8 등, USB 디버깅), Windows PC.
- **수요일부터 실제 업무에 사용.** 수동 방식은 절대 망가뜨리지 말 것.
- 사용자가 싫어하는 것:
  - "이거 AI예요? / 자동응답이에요?" 같은 질문을 예시·시험 문장으로 쓰는 것. **실제로 그런 질문을 하는 손님은 없다고 여러 번 말함.** 쓰지 말 것.
  - 이미 한 걸 다시 시키는 것, 할 수 없는 걸 할 수 있는 척하는 것.
- 사용자 PC 를 직접 만지는 일(설치·파일 넣기·바탕화면 정리)은 **사용자 PC 의 Claude 앱**이 함. 클라우드 대화에서는 PC 에 손이 안 닿음.
  → 프로그램 수정·녹음 다듬기는 여기서, PC 작업은 PC 앱에 붙여 넣을 요청문을 만들어 줌.

## 원칙
- 무료: 유료 API 없이 PC 에서 돌아감 (engine: free, 한국어 음성인식 sherpa-onnx `models/ko`, 상황표 RuleBrain).
- 목소리는 **사용자 본인 녹음만** 사용 (문장별 녹음 클립을 그대로 재생). 사람이라고 거짓말하는 녹음은 넣지 않음.
- 본인 인증·결제·계약은 AI 가 하지 않고 사람에게 넘김.
- 커밋 금지: 녹음(clips), `data/`, `logs/`, `config*.yaml`, `.env`, 고객 정보. 커밋 메시지에 모델 이름 넣지 않기.
- 작업 브랜치: **`claude/voice-clone-call-automation-iizrpp`** — 프로그램의 '업데이트(u)'가 이 브랜치 ZIP 을 받으므로 **브랜치 이름을 바꾸면 안 됨**. 여기에 커밋·푸시.
- 시험: `cd call-agent && python -m pytest tests -q` (현재 36개 통과). 바꾸면 시험도 추가.

## 프로그램 구조 (call-agent/)
- `전화상담.bat` → `python main.py menu` (메뉴: 1 점검, 2 폰 연결, 3 녹음 넣기, 4 연습, 5/6 1·2번 폰으로 고객 전화,
  7 아무 번호, 8 녹음대본, 9 프로필, **a 자리 비움 자동 모드**, k 카톡 테스트, s 소리 테스트, u 업데이트)
- `callagent/` : session.py(통화 진행), rules.py(상황표 대답), away.py(자리 비움 모드), config.py(프로필·내설정),
  menu.py, updater.py, dialer.py(adb 걸기·끊기·통화상태), notify.py(카톡), clips.py(녹음 클립), customers.py(엑셀)
- 프로필: `profiles/<이름>/` = profile.yaml(설정) + scenarios.yaml(상황표) + 녹음대본.txt
- 녹음 넣기: 메뉴 3 에서 ZIP(clip_###.wav + clips.yaml). 메뉴를 켤 때 다운로드 폴더의 새 녹음 ZIP 을 찾아 Enter 한 번으로 넣기도 함.
- 카톡 대화방 이름: `data/내설정.yaml` 에 저장 (업데이트해도 유지).

## 에셜론 현재 상태
- `profiles/에셜론/` : 녹음(clips, 사용자 PC 에만 있음)과 **녹음대본.txt (번호 1~41)** 의 원본. 아래 세 프로필이 이 녹음을 같이 씀.
- `profiles/에셜론1_정리본/` : 스크립트1. 첫인사 39 → 3 → 13(번호 요청) → 15. 반론: 광고 중 18·19 / 생각해볼게 20 / 관심 없음 20→16 / 왜 무료 22 / 돈 드나 23 ...
- `profiles/에셜론2_업종별/` : 스크립트2. 첫인사 1, **미용실·네일숍·피부관리숍은 첫인사 2번("네이버 지도 보고 연락드렸습니다")**.
  업종 멘트(음식점 4·5·6 / 미용실 7·8 / 네일 9·11 / 피부 10·11) → 12(제안서) → 40(유선번호) → 14·15.
- `profiles/에셜론_자동/` : **기본 프로필.** 엑셀 '업종' 칸으로 손님마다 스크립트 자동 선택
  (음식점·미용실·네일숍·피부관리숍 → 스크립트2, 그 외 → 스크립트1, 엑셀 '스크립트' 칸 1/2 가 있으면 우선).
- 넘겨받기(handoff): 상황표에 없는 질문·담당자 요청 → 31/33번("담당자가 확인해서 안내드리겠습니다").
- 자리 비움 자동 모드(메뉴 a, 켤 때만): 자동 걸기 → 짧은 첫마디+조용함으로 받음 판단(컬러링·통신사 안내 무시) →
  30초 무응답 '부재' → 끝나면 바로 엑셀 기록 → 넘겨받을 상황이면 알림음+카톡, 10초 안에 t 안 누르면 41번(없으면 28번)으로 마무리.

## 녹음 현황
- 1~40 완성 (34번 없음, 안 씀). 제안서·유선번호·발행·무상·비교 문장은 문장 전체 재녹음으로 교체 완료.
- **임시 녹음**(연습 녹음에서 비슷한 문장으로 대신): 24~31, 33, 35 → 사용자가 녹음해 주면 교체.
- **41번** "네, 확인해보고 다시 연락드리겠습니다. 감사합니다." 아직 녹음 안 됨.
- 다듬기: 문장 전체를 녹음받아 바꾸는 게 원칙 (단어만 잘라 끼워 넣으면 어색하다고 해서 그만둠).
- 도구: `tools/add_clips.py` (ffmpeg 필요). **원본 녹음은 이 저장소에 없음** → 녹음 작업 전에
  사용자에게 PC 의 `에셜론_완성녹음.zip`(최신) 과 새 녹음 파일을 올려 달라고 할 것.
  ```
  python tools/add_clips.py segments 새녹음.m4a                      # 문장 위치 + 받아쓰기
  python tools/add_clips.py add 에셜론_완성녹음.zip 새녹음.m4a 41=1.2-5.8 -o 에셜론_완성녹음.zip
  ```
  같은 문장을 여러 번 읽었으면 **마지막 것**을 씀. 결과 ZIP 과 확인용 mp3 를 사용자에게 보내고,
  녹음대본.txt 글도 실제 읽은 말에 맞춰 고침.

   → 에셜론1_정리본·에셜론2_업종별 scenarios.yaml 에 상황 추가 (keywords 넉넉히, `interrupt: true` 로 질문 중에도 대답 후 이어가기),
   녹음대본.txt 에 42번부터 문장 추가 → 녹음 목록을 번호와 함께 사용자에게 전달 → 녹음 오면 add_clips 로 ZIP.
2. 41번, 임시 녹음(24~31, 33, 35) 녹음 받기.
3. 수요일 전 실제 시험 (사용자 다른 폰 번호를 엑셀 맨 위에): 받으면 첫인사 / 안 받으면 30초 뒤 부재 /
   녹음에 없는 질문("그거 하면 리뷰가 몇 개 올라가요?")·"담당자 바꿔 주세요" → 알림 / 먼저 끊으면 종료.
